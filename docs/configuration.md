# Configuration

The router, sidecar and autoscaler read their settings from environment variables. Defaults:

```
POLICY=relay                     # relay | round_robin | least_loaded | consistent_hash
BLOCK_SIZE_TOKENS=64
SCORE_ALPHA=1.0
SCORE_BETA=0.5
SCORE_GAMMA=0.5
LOAD_BOUND_C=1.25
QUEUE_MAX=256
STALL_TIMEOUT_MS=3000
MAX_FAILOVERS=2
SIDECAR_SCRAPE_MS=250
WORKER_MODEL=
AUTOSCALER_TARGET_QUEUE_PER_WORKER=4
AUTOSCALER_TARGET_TTFT_P95_MS=800
AUTOSCALER_MIN_REPLICAS=2
AUTOSCALER_MAX_REPLICAS=8
```

Additional knobs (see `router/internal/config/config.go`): `FIRST_TOKEN_TIMEOUT_MS=30000`, `MAX_INFLIGHT_PER_WORKER=8`,
`QUEUE_DEADLINE_MS=30000`, `WORKER_FLAVOR=llamacpp|vllm`, `CHAT_TEMPLATE=chatml|llama3`, `TOKENIZER=remote|approx`,
`WORKERS` / `WORKERS_FILE` / `WORKER_DNS`, `SIDECAR_TIMEOUT_MS=1500`, `HEALTH_INTERVAL_MS=1000`,
`BREAKER_THRESHOLD=3`, `BREAKER_COOLDOWN_MS=5000`, `CONSISTENT_HASH_BLOCKS=1`, `API_KEY`, `OTEL_EXPORTER_OTLP_ENDPOINT`.
